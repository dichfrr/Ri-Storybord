# CineSetup AI

AI-assisted cinematography breakdown tool.

Upload a film frame and get an estimated camera, lens, lighting, blocking, and a clean top-view lighting diagram.

## MVP

- Upload a reference frame
- Cinematography analysis
- Estimated camera/lens information
- Lighting direction and quality
- Subject/camera relationship
- Top-view lighting diagram
- Recreation notes

> Estimates are visual interpretations, not guaranteed metadata. A single frame cannot reliably identify the exact camera, lens, or lighting equipment.

## Status

Early MVP — UI and analysis pipeline are being built incrementally.
